# 🧪 Verilog Repository Structure

My Verilog repositories generally follow this structure:

```text
project-name/
├── design.v
├── testbench.v
├── README.md
└── simulation/
```

For example:

```text
and-gate-verilog/
├── and_gate.v
├── and_gate_tb.v
└── README.md
```

The goal is to make each project simple enough for engineering students to understand and reproduce.
